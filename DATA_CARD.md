# Data card

## Real dataset (not shipped): Edge-IIoTset

- Provider: Ferrag et al., Edge-IIoTset cyber security dataset of IoT and IIoT.
- Where to obtain: Kaggle `mohamedamineferrag/edgeiiotset-cyber-security-dataset-of-iot-iiot`
  or IEEE Dataport, doi 10.21227/mbc1-1h68. Terms are the provider's and apply
  separately from this repository's MIT license. Nothing from the dataset is redistributed here.
- Record unit: one network flow / packet record with a categorical attack label.
- Target: `Attack_type` style label. This repository fixes the 15-class order in
  `configs/classes.yaml` (Table 1 order: Normal first, MITM last) and derives the binary
  target Normal vs Attack from the same label column for a separately trained model.
- Columns: the source paper reports 48 retained features after dropping constant,
  duplicate and metadata columns (frame number, timestamp, raw IP). The paper does not list
  them. `configs/feature_manifest_paper.yaml` therefore carries 48 placeholder slots
  `feature_01..feature_48` that the user must overwrite with the column names produced by
  their own preprocessing. The raw release columns are not assumed equal to those slots.
- Splits: stratified 80/20 outer split; 5-fold stratified inner CV inside the training
  partition (paper). The paper reports 1,527,736 / 381,935 rows; this repository recomputes
  the split from whatever table is supplied.
- Missingness: handled per column with statistics from the training partition only
  (drop columns above 40% missing, inf to the training column maximum, median for numeric,
  mode for categorical, then Min-Max to [0, 1]).
- Known shortcut risks the audits look for: identifier-like columns, placeholder values
  whose presence predicts the label (structurally undefined protocol fields), exact
  duplicate flows across the split. These are `proposed` checks on real data.

## Shipped fixture: examples/fixtures/v1

Authored synthetic demonstration data. Fictional identifiers. Not derived from any person,
company, account or dataset. Generated by `tools/make_fixture.py` seed 42, version v1.

- Rows: about 9,000 plus 30 deliberate exact duplicates; 48 features named
  `feature_01..feature_48`; one synthetic `frame.number` metadata column the adapter drops;
  `label` with the 15 class names.
- Class proportions mirror the imbalance of the paper's Table 1 (Normal about 72%,
  MITM about 0.1%, held at a minimum of 12 rows so stratified folds work). Values are drawn
  from parametric distributions chosen in the generator; nothing is sampled from Edge-IIoTset.
- Deliberate defects for the pipeline to handle: about 1.5% NaN in six columns, eight
  `+inf` values in one column, `feature_40` structurally zero for the DDoS classes (so the
  placeholder audit has something to find), and the duplicate rows.
- Regenerate: `python tools/make_fixture.py --out examples/fixtures/v1 --seed 42`; the
  SHA-256 in `fixture_manifest.json` must match.
